Villa Caetano Log

Files:
- index.html — main log page
- open-log.html — open log report
- assets/black-logo.png and assets/logo-white.png — Villa Caetano logos
- assets/supabase-config.js — Supabase project settings
- supabase/add-entry-type.sql — SQL for the entry_type column if not already applied

The main page keeps the Log Register visible on mobile. Open Log Report is a compact secondary button.
The report supports sharing an image of the report and sharing the full report text.
